# Play Store Assets

Upload these files in Google Play Console under the default store listing.

## Required fields

- App icon: `app-icon-512.png`
- Feature graphic: `feature-graphic-1024x500.png`
- Phone screenshots:
  - `phone-screenshots/phone-01-shelly.png`
  - `phone-screenshots/phone-02-sensor.png`
  - `phone-screenshots/phone-03-rule.png`
  - `phone-screenshots/phone-04-diagnostics.png`
- 7-inch tablet screenshots:
  - `tablet-7-screenshots/tablet-7-01-shelly.png`
  - `tablet-7-screenshots/tablet-7-02-sensor.png`
  - `tablet-7-screenshots/tablet-7-03-rule.png`
  - `tablet-7-screenshots/tablet-7-04-diagnostics.png`
- 10-inch tablet screenshots:
  - `tablet-10-screenshots/tablet-10-01-shelly.png`
  - `tablet-10-screenshots/tablet-10-02-sensor.png`
  - `tablet-10-screenshots/tablet-10-03-rule.png`
  - `tablet-10-screenshots/tablet-10-04-diagnostics.png`

The YouTube video, Chromebook, and Android XR assets are optional for the first
internal/closed testing setup.
