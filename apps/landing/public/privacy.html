Privacy Policy

Local Climate Link. Last updated: July 6, 2026.

Local-first operation

Local Climate Link configures supported BLE thermometers and a local Shelly Plug S Gen3. The phone is a configurator. The automation runs locally on the user's Shelly device after setup.

Data the app handles locally

The app may process these items on the user's device or local network:

  • BLE advertisements from supported thermometers.
  • Temperature, humidity, battery level, RSSI, and last-seen time.
  • Shelly local IP address, model, firmware, script status, and relay state.
  • Generated automation configuration and local diagnostic logs.

No default cloud collection

The app does not require an account, cloud service, Home Assistant, MQTT broker, analytics SDK, or third-party telemetry. Local Climate Link does not upload diagnostic data by default.

Bluetooth, nearby devices, and local network

Bluetooth permissions are used for foreground setup scans of supported thermometers. On older Android versions, Android may require location permission for BLE scanning. Local Climate Link does not use BLE scan data to determine the user's physical location. Local network access is used to communicate directly with the user's Shelly plug.

Diagnostics and sharing

Diagnostics export is user-initiated. The app is designed to redact secrets by default. Users should review exported diagnostics before sharing them.
